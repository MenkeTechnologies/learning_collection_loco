Kotlin/Spring Boot → Rust/Loco port · loco-rs 0.16 + axum 0.8 + sea-orm 1.1 + tokio 1.45 + sqlx-sqlite · CRUD over one entity, 1:1 route parity with the Spring controller it replaces.

>_EXECUTIVE SUMMARY

learning_collection_loco is a complete Rust replacement for a small Kotlin/Spring Boot REST service. The original is a Spring Boot 4.0.4 + Kotlin 2.3.20 + Spring Data JPA + Spring Data REST app over MySQL with one entity and ~13 endpoints. The port is 488 lines of Rust across 25 files, single binary, sub-second cold boot, SQLite by default with a one-flag swap to MySQL/Postgres. Loco 0.16 supplies the Hooks lifecycle, routing assembly, and built-in /_health / /_ping / /_readiness endpoints; Axum 0.8 handles HTTP; SeaORM 1.1 replaces JPA/Hibernate; sea-orm-migration replaces Flyway. No JVM. No GC pauses. No Hibernate session-per-request. No 2-second startup banner.

$SUBSYSTEM BREAKDOWN

Five subsystems with a clear hierarchy: the HTTP layer (Loco/Axum) dispatches into controllers, which talk to SeaORM, which talks to sqlx, which talks to SQLite. Migrations sit beside the model layer, gated by auto_migrate: true in config/development.yaml.

HTTP & Routing

Loco 0.16 hosts the app via create_app::<App, Migrator>. The Hooks impl in src/app.rs assembles AppRoutes::with_default_routes and chains controllers::learning::routes() + controllers::home::routes(). Axum 0.8 supplies get/delete handlers, State<AppContext>, Query<T>, Path<T> extractors. #[debug_handler] attached for clearer compile errors.

Persistence

SeaORM 1.1 with sqlx-sqlite + sqlx-postgres features and runtime-tokio-rustls. One entity (learning_collections) generated via sea-orm-codegen; a thin user wrapper at src/models/learning_collections.rs implements ActiveModelBehavior. chrono supplies DateTimeWithTimeZone for date_added / created_at / updated_at.

Migrations

Separate migration crate (path dep). MigratorTrait registers m20260601_044042_learning_collections. The migration uses Loco's schema::create_table helper with ColType::{PkAuto, String, TimestampWithTimeZone}. auto_migrate: true in dev/test configs runs migrations on boot; production should run cargo loco db migrate explicitly.

Config

YAML configs under config/{development,test,production}.yaml drive: server bind, DB URI, CORS (replaces Spring WebConfig), logger level, JWT secret slot, auto_migrate toggle. Environment selection via LOCO_ENV / loco_rs::environment::Environment.

Runtime

Tokio 1.45 multi-thread runtime, async-trait 0.1 for the Hooks trait. tracing + tracing-subscriber with env-filter + json features for structured logs. regex 1.11, validator 0.20, uuid 1.6 (v4), rand 0.8 for shuffle/choose. serde + serde_json 1 for wire format.

Tests & Tooling

loco-rs with the testing feature gates a request::<App, _, _> harness that boots an in-memory app per test. serial_test serialises DB-touching tests; insta snapshots model output; rstest for parameterised cases. CI runs cargo fmt --check + build/test in .github/workflows/ci.yaml.

&DEPENDENCY SURFACE

14 direct dependencies (10 runtime + 4 dev) resolve to 559 packages in Cargo.lock — Loco's transitive closure dominates (Axum, Tower, hyper, sqlx, tokio-rustls, openapi-tooling, validator). The crate itself adds nothing exotic on top: chrono, uuid, regex, rand, validator are the only first-party picks beyond what Loco pulls in for free.

loco-rs 0.16

The framework: Hooks trait, AppContext, AppRoutes, boot, cli, prelude. Re-exports Axum's handler conveniences. testing feature gates the integration harness.

axum 0.8

HTTP server — get/delete, State/Path/Query extractors, Response assembly. Used directly via loco_rs::prelude::*.

sea-orm 1.1

Async ORM. Features: sqlx-sqlite + sqlx-postgres (drop one to drop ~30 transitive deps), runtime-tokio-rustls, macros. Generates the Entity/Model/ActiveModel/Column set.

sea-orm-migration (via path)

MigratorTrait + SchemaManager + create_table/drop_table. Pulled through the local migration crate.

tokio 1.45

rt-multi-thread only — everything else (macros, fs, signal) comes from Loco/Axum transitives.

chrono 0.4

UTC timestamps in add, model columns. DateTimeWithTimeZone bridge through SeaORM.

serde 1 + serde_json 1

Wire-format encode for every JSON-returning handler.

tracing 0.1 + tracing-subscriber 0.3

Structured logs with env-filter + json output features.

rand 0.8

thread_rng + SliceRandom for random/randoms handlers.

regex 1.11, uuid 1.6 (v4), validator 0.20

Stock conveniences kept for future use — not load-bearing in the current handler set.

async-trait 0.1

Required by the Hooks trait until async fns in traits stabilises everywhere.

dev: serial_test + rstest + insta

#[serial] for DB-touching tests, rstest for table-driven cases, insta with redactions,yaml,filters for snapshot assertions.
